# MVP PRD

## Summary
Create a cozy virtual bookshelf for manually organizing online resources. The MVP must work locally and provide a clean foundation for secure hosting later.

## Goals
- Create, view, edit, and delete books.
- Create sections inside books.
- Create resources with URL, title, source type, notes, and tags.
- Place the same resource in multiple book sections.
- Browse a bookshelf overview and book table of contents.

## Non-Goals
- User accounts.
- AI categorization.
- URL scraping.
- Public sharing.
- Hosted deployment.

## Acceptance Criteria
- A user can create two books and sections in each.
- A user can create one resource and place it in both books under different sections.
- A user can add and remove tags from a resource.
- Data persists after page reload and backend restart.
